# TimeWastr
> No more squandering your precious awkward periods of time. Not all time is made equal, but it doesn't mean you can't use it!

TimeWastr is an app designed to allow you to fill awkward (or normal) gaps in your schedule. Create an account, create activities, assign them ingredients or categories, set a timer, and get an activity perfectly fit to fill that awkward gap. This app's main motivation is to prevent choice paralysis which can lead to doomscrolling and wasting of time.

## Features:
- Create an account
- Create activities with a minimum number of minutes needed to enjoy the activity 
  - Assign activities ingredient labels, custom tags to fit your needs best (for example: at home, during class, access to laptop, etc.)
  - Assign a category
- Set a timer along with what ingredients you can use at the moment
- Cook up an activity that fits your needs
- Recook the activity if you are unsatisfied
